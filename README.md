# MedRi Plan content

This repository serves the public JSON content package for MedRi Plan. The package covers public course information, examination dates, rotations and study questions. Official timetable sources are linked from the package. The package contains no student submissions or progress data.

## Anatomy question credits

The anatomy questions are translated and adapted from chapters 7 and 8 of *Anatomy and Physiology 2e* by J. Gordon Betts, Peter Desaix, Eddie Johnson, Jody E. Johnson, Oksana Korol, Dean Kruse, Brandon Poe, James A. Wise, Mark Womble, and Kelly A. Young, OpenStax, Rice University. Source is [OpenStax commit b0058a743b](https://github.com/openstax/osbooks-anatomy-physiology/tree/b0058a743bdd2cc08196abaaa7d5469970c0d80c), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changes include a Croatian translation, some modified answer choices and added explanations.
